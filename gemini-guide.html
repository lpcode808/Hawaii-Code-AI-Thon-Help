How It Works

Here's the whole process in four steps. You don't need to understand code — you just describe what you want and the AI builds it.

  1. Describe your idea in plain English — "I need a tip calculator that splits the bill"
  2. AI writes the instructions — you'll get a working app in about 60 seconds
  3. Test and improve — try it out, tell the AI what to fix or change
  4. Share it — put it online with a link anyone can open

That's it. Now pick which AI tool to use:

Choose Your Path

Not sure which to pick? Start with Gemini Canvas — it's the easiest path and you'll see your app instantly. You can always switch to AI Studio if you hit a usage limit or want more control.

Account tip (School / Hawaii DOE): A personal Google account gives you the fewest surprises on both tools. School / HIDOE (Google Workspace for Education) accounts can now share Canvas creations to Google Classroom and export to Google Sites (where enabled by your admin), but public share links and AI Studio may still be restricted. Whatever account you use, keep real student names and private data out of your prompts.

Gemini + Canvas

gemini.google.com

Build and preview apps right beside the chat, then export straight to Google Sites in one click. The easiest starting point.

  • Live preview — see your app instantly
  • One-click Export to Google Sites (no copy-paste)
  • Chat to iterate, click elements, or upload a sketch
  • Free tier available (Gemini Flash)
  • School/HIDOE accounts may restrict public links
  • Free usage limits refresh every 5 hours

Google AI Studio

aistudio.google.com/build

Build mode gives you live preview, full code view, and ZIP / GitHub export — plus a generous free tier when Canvas hits a limit.

  • Generous free tier (great fallback if Canvas pauses)
  • Build mode has live preview + full code editor
  • Built-in Versions history, Download ZIP & GitHub sync
  • Chat mode also works for single offline HTML files
  • Slightly more developer-focused layout than Canvas
  • Usually requires a personal Google account
Which model? Both paths default to Gemini Flash, which is free and plenty capable for building apps. Stick with the default — no need to upgrade or change settings.

VIBE CODING ASSISTANT - Single File App Generator

You are an expert at creating simple, functional single-file web apps for coding novices. Your goal is to turn rough ideas into working prototypes that can be opened directly in a web browser.

CONSTRAINTS:
- Generate ONE complete HTML file containing CSS and JavaScript
- No external dependencies (no external libraries, APIs, fonts, or CDNs)
- Apps must work when opened locally on desktop and look good on a phone (no hidden buttons or horizontal scroll)
- Include clear, educational comments explaining key concepts
- Keep editable text/content in one clearly labeled section near the top of the script
- Start with 2 realistic sample items (or a "Load sample data" button) so the app doesn't open empty
- Keep all responses under 200 words (except code generation)

CODE REQUIREMENTS:
- Use semantic HTML structure
- Include responsive, mobile-friendly CSS styling
- Add JavaScript for interactivity (use localStorage if the app saves entries)

SUGGESTED APP TYPES:
- Productivity tools (timers, calculators, note-takers)

- Utilities (unit converters, password generators)
- Trackers (habits, expenses, tasks)
- Educational tools (flashcards, quizzes, name pickers)

WORKFLOW:
1. If user gives vague idea, ask 1-2 clarifying questions
2. Generate complete, commented code

4. Suggest 2-3 simple modifications they could try

Step-by-Step Guide

Click the tab for your chosen path, then follow the numbered steps.

1 Open Gemini Canvas
  1. Go to gemini.google.com (or try gemini.google.com/canvas)
  2. Sign in with your personal Google account (or your school/HIDOE account if Gemini + Google Sites/Classroom are enabled)
  3. In the prompt box, click + (Upload and tools) → More tools → Canvas. You'll see a Canvas chip appear in the message box.
Already logged into your school account? Open a private/incognito window (Ctrl+Shift+N in Chrome) and sign in with your personal Gmail there.
2 Paste the super prompt + describe your app

Paste the super prompt you copied (from above), then press Enter twice and type your app idea below it — all in one message. Example:

[the super prompt you already copied]

Build me a conference contact tracker. Simple text inputs for name, note, and follow-up action. Add a timestamp automatically. Let me copy everything to clipboard at the end.

Hit Send and wait 30–90 seconds. Gemini will think, then generate your app in the Canvas panel.

Bonus move — sketch it! You can also click + to upload a photo of a hand-drawn paper sketch and ask Gemini Canvas to turn your sketch into a working web app.
3 Test your app in Canvas

When Gemini generates your app, the Canvas panel on the right opens with a live preview:

  • Preview — try your working app, click every button, fill in every field
  • Code — see and edit the HTML/CSS/JS code directly
  • Select & ask — click a part of the app and describe what you want changed in plain English
  • Undo / Redo — step back to a previous version anytime from the top bar
Heads up about saving in Canvas preview: Gemini's Canvas preview sandbox can look like it saved your data, then lose it when you reload. That's a preview-window quirk, not necessarily a bug in your code — test saving after you export or open the file in a real browser tab.
4 Iterate in the chat (small steps)

To make changes, type what you want in the chat. One change at a time:

Make the background dark gray and the text white. Keep buttons green.
The "add" button doesn't do anything when I click it. Fix just this.
Add a "clear all" button that asks "Are you sure?" before deleting.

Canvas updates the preview automatically after each change. If a long chat starts breaking things that used to work, see Reroll or Translate below.

5 Export, share, or copy your code

When you're happy with your app, pick how you want to take it out of Canvas:

  • Fastest to publish online: Click Export → Google Sites right from the Canvas toolbar — it opens a ready-to-publish Google Site draft with your app already embedded.
  • Sharing with a class (School / HIDOE): Click Share → Share to Classroom to attach your app straight to a Google Classroom post or assignment (if enabled by your school).
  • Get the raw HTML file (for GitHub Pages, offline use, or editing):
    1. Click the Code tab in the Canvas panel
    2. Click inside the code text itself, select all (Ctrl+A / Cmd+A), and copy (Ctrl+C / Cmd+C)
    3. Test instantly in HTML Playground or edit/save in vscode.dev — no install needed
Common trap: The Copy button under Gemini's chat message copies the chat text, not your app. Always open the Code tab first before copying. Also note: Gemini's public g.co/gemini/share links let anyone with the link view/edit app data and don't reliably save on iPhone — use Google Sites or GitHub Pages for a real shareable URL.

To save index.html to your Desktop:

Mac instructions (TextEdit)
  1. Open TextEdit (Cmd+Space, type "TextEdit")
  2. Go to Format → Make Plain Text (critical!)
  3. Paste your code (Cmd+V)
  4. File → Save, name it index.html, save to Desktop
  5. When asked about the file extension, click "Don't Append" so it stays .html (not .txt)
Windows instructions (Notepad)
  1. Open Notepad (search in Start menu)
  2. Paste your code (Ctrl+V)
  3. File → Save As
  4. Change "Save as type" to "All Files (*.*)"
  5. Name it index.html and save to Desktop
VS Code or vscode.dev (either platform — easiest)
  1. Open vscode.dev in Chrome (zero install) or desktop VS Code
  2. New file: Ctrl+N / Cmd+N
  3. Paste your code
  4. Save: Ctrl+S / Cmd+S, name it index.html

Double-click index.html on your Desktop to test it in Chrome or Safari. When iterating in Chat mode, copy your working code back into the prompt so Gemini doesn't lose track of earlier changes.

Prompting & Iteration Tips

The first version is never perfect — that's expected. The rate of feedback is your speed limit: small steps, small rerolls.

Write prompt → Generate → Test → Find problem → Improve prompt → Repeat

Reroll, or Translate?

01 · Reroll (Stay in Gemini)

Behavior is broken (button does nothing, won't save)? Describe what you expected in one sentence and run again. If a long chat starts breaking things that used to work (context rot), copy your working code into a fresh chat and keep going.

02 · Translate (Leave Gemini)

It works, just a typo, label, or color is off? Don't reroll for a typo. Open your HTML file in vscode.dev (free in your browser, no install) and change that one word or color yourself.

Two Moves Past Prompting

Have the AI interview you

Idea still fuzzy? Don't try to write one perfect prompt. Ask: "Ask me 5 quick questions to help me design a simple web app for [my idea] before you write any code."

Point, don't describe

Paste a screenshot of what looks wrong (or a photo of a paper sketch) and point at the exact thing you want changed.

Golden Rules

  • One change at a time. Don't ask for 5 things at once.
  • Be specific. "Fix the button" → "The Add Entry button doesn't respond when clicked. Fix just this."
  • Describe what you see vs. what you expect. "When I click Submit, nothing happens. I expected it to add a new row to the list."
  • Test it with a real person. Hand your app to a classmate or colleague, bite your tongue while they try it, ask "Say more…", then decide what to fix.

Troubleshooting

If It Goes Sideways (Quick Rescue)

It got confused (context rot)

Each fix starts breaking things that used to work? Copy your last working code into a brand-new chat and ask for one change from there.

It stopped answering (usage limit)

Canvas free limits refresh every 5 hours. Switch to Google AI Studio (or pair up with a neighbor) and paste your working code to keep going.

Gemini is off on my school/HIDOE account

Open an incognito window (Ctrl+Shift+N) and sign in with a personal Gmail. Keep real student names and private info out of prompts.

I'm on a phone

You can build and test in Gemini on your phone, but download or export the final file from a laptop or Chromebook later for full editing controls.

I have no idea what to build

Check the App Ideas table above for a full list of starter projects by category, or ask Gemini to interview you with 5 quick questions about a daily annoyance.

File opened as text, not a web page
  • Fastest skip: Paste your HTML into HTML Playground or save it using vscode.dev.
  • Mac TextEdit: You forgot Format → Make Plain Text. Save again.
  • Windows: You saved as .txt. Rename the file and change .txt to .html.
  • Either: Right-click the file → Open With → Chrome (or Firefox)
App doesn't do anything when I click buttons
  • Make sure you copied ALL the code from the Code tab (not the chat reply!) — verify you got <!DOCTYPE html> at the start and </html> at the end
  • Open browser console: press F12 (Mac: Cmd+Option+J) → Console tab → look for red errors
  • Copy the red error text and paste it back to Gemini: "I'm getting this error: [paste]. Fix it."
Gemini stopped generating partway through
  • Look for a "Continue" button and click it
  • Or type: "Continue from where you left off — the code got cut off."
Google Sites shows a blank app
  • If you built in Gemini Canvas, try one-click Export → Google Sites instead of manual copy-paste
  • If embedding manually, verify you pasted the FULL code from <!DOCTYPE html> to </html>
  • Try a hard refresh: Ctrl+Shift+R / Cmd+Shift+R
  • Some apps won't work inside Sites — try GitHub Pages instead
GitHub Pages shows 404
  • Make sure the file is named exactly index.html (lowercase, no spaces)
  • Wait 3 minutes — Pages takes time on the first deploy
  • Check Settings → Pages — is it showing the green banner yet?
I want to start completely over
  • Start a new chat (don't reuse a confused thread)
  • Paste the super prompt again (or paste your last working code)
  • Describe the same app more simply, or try a new idea
I'm completely stuck and nothing is working

Start fresh with the simplest possible test:

  1. Open a brand new Gemini chat
  2. Paste the super prompt
  3. Type: Make me a button that says "Hello!" when I click it.
  4. If that works, you know the tool is working — now try your real idea again with a simpler description

If even that doesn't work, ask your facilitator for help or try switching between Canvas and AI Studio.

PHASE 5: DEPLOY
- Ask how they want to share it:
  A) Google Sites (fastest): In Gemini Canvas click Export > Google Sites > Publish. Or manually at sites.google.com > Insert > Embed (or Pages > Full page embed) > paste HTML > Publish. Test on a phone!
  B) Google Classroom (school/HIDOE): In Gemini Canvas click Share > Share to Classroom (if admin-enabled).
  C) GitHub Pages (most robust): github.com/signup > new repo > upload index.html (or push from AI Studio Settings > GitHub) > Settings > Pages > main branch.

Glossary

Real terms you'll hear developers use. You've already been doing all of this — now you know the words for it.

HTML
The language that defines the structure of a web page — headings, buttons, text fields. Your app is one HTML file.
CSS
The part that controls how things look — colors, fonts, spacing, layout. "Make it dark mode" is a CSS change.
JavaScript (JS)
The part that makes things happen — button clicks, calculations, saving data. The "brain" of your app.
Deploy
Putting your app on the internet so anyone can open it with a URL. You did this with Google Sites or GitHub Pages.
Repository (repo)
A project folder on GitHub. It holds your files and tracks every change you make.
Commit
Saving a change on GitHub. Each commit is a snapshot you can go back to — like version history in Google Docs.
Code
Text instructions that tell a computer what to do. Your HTML file is code — but the AI wrote it for you.
Iterate
Making something better one small change at a time. Test → find a problem → fix it → repeat. That's iteration.
Prompt
What you type to tell the AI what to do. A good prompt is specific: "Add a dark mode toggle" beats "make it better."
localhost
Your own computer. When you double-click your HTML file and it opens in the browser, that's running "locally."

Remember: make first, code later. You describe what you want, the AI builds it. Have fun!
